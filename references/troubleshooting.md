# 显示问题排查手册（通用）

## 0. 30 秒定性流程

```
用户说"看不见 / 看不清"
   │
   ├─ 看不见的是"某几类字符"吗？
   │     ├─ 只有汉字空白，数字/符号正常 ────────────→ 【字体缺字形】改字体
   │     └─ 全部字符都没有 / 整个文件空白 ──────────→ 【编码或文件本身】先看字节
   │
   ├─ 是"看得见但颜色太淡 / 像背景色"吗？ ──────────→ 【配色对比度】改配色
   │
   └─ 是"改了设置不生效 / 又变回去"吗？ ───────────→ 【流程问题】程序没退出 / 改错文件
```

## 1. 判据一：哪些字符不显示

| 观察到的现象 | 结论 |
|---|---|
| 只有汉字空白，`// 2^31`、`→`、`*` 都正常 | **字体缺字形**（该字体无汉字，回退绘制丢颜色） |
| 连英文都没了、整片空白 | 不是字体问题；看文件字节与编码 |
| 显示成 `锟斤拷` / `璁颁簨` / `????` | 编码不匹配 |
| 显示成方框 `□□□` | 字体缺字形但占了位（另一种回退表现） |
| **选中（或全选）后就正常显示** | **字符数据完全正确**，问题在绘制层：只需改字体/颜色，**别碰编码** |

**"选中才显示"是最强的证据**——它一次性排除了编码、文件损坏、解码失败等所有"数据层"原因。看到这个现象，直接去改字体和颜色。

## 2. 判据二：数据到底对不对

不确定是"字没进去"还是"字进去了但不显示"时，**直接读源文件字节**：

```python
data = open("目标文件", "rb").read()
print(len(data), sum(1 for b in data if b > 127))   # 非 ASCII 字节数
for enc in ("utf-8", "gbk"):
    try:
        print(enc, "OK"); print(data.decode(enc)[:500])
    except Exception as e:
        print(enc, "FAIL", e)
```

- **UTF-8 能解、GBK 报错** → 文件是 UTF-8
- **GBK 能解、UTF-8 报错** → 文件是 GBK/ANSI
- 两者都能解 → 可能都是 ASCII，或含少量歧义字节，看非 ASCII 数量
- **能解出正确中文** → 数据没问题，问题在显示层

## 3. 判据三：颜色与背景

- **浅底（白底）**：前景必须是**深色**（如 `#606060`、`#007000`）。浅绿、浅黄、浅灰在白底上等于隐形。
- **深底**：前景必须是**浅色**。
- **最坑的写法**：使用"跟随系统主题"的颜色（Dev-C++ 的 `clHighlight`、某些编辑器的 `default`），在白底/深底之间切换时会撞色。
- **验证方法**：把注释色临时改成 `#FF00FF`（亮紫）或纯红，如果还是看不见 → 不是颜色问题，回去查字体。

## 4. 判据四：配置有没有生效

按可能性排序：

1. **程序没关** —— 运行中改配置会被忽略，退出时还会被内存值覆盖回写。**这是第一位原因**（Dev-C++、Code::Blocks、JetBrains 均实测）。
2. **改错了文件** —— 同一个编辑器可能有多个配置位置：安装目录（便携版）、`%APPDATA%`、项目级（VS Code 的 `.vscode/settings.json`）、注册表（Visual Studio）。多用户/多版本时路径还不一样。
3. **设置被更高优先级覆盖** —— VS Code 工作区设置 > 用户设置；Code::Blocks 的元素字体 > 全局字体；JetBrains 配色方案字体 > 全局字体。
4. **缓存** —— 少数编辑器需要重启才生效。

**排查动作**：改完立刻 `os.stat()` 看文件 mtime 是否变化、内容是否被回写；若被回写，就是原因 1。

## 5. 常见现象速查（跨编辑器）

| 现象 | 最可能根因 | 第一动作 |
|---|---|---|
| 汉字空白、ASCII 正常 | 字体缺字形 | 换 `NSimSun` / `Microsoft YaHei` |
| 选中后正常 | 同上（绘制层） | 同上，别动编码 |
| 打开文件满屏乱码 | 编码不匹配 | 切/猜编码（VS Code 开 `files.autoGuessEncoding`） |
| 注释看不清但字符都在 | 配色对比度 | 注释色换深色 |
| 改了 ini/conf 无反应 | 程序没退出 | 关闭程序再改 |
| 改了设置重启后复原 | 改错文件 / 被覆盖 | 关程序 → 确认 mtime → 重改 |
| 只有某一个项目出问题 | 项目级设置覆盖 | 查项目目录下的配置文件 |
| 终端窗口里中文不正常 | 终端字体 | 改终端设置，与编辑器无关 |

## 6. 防翻车清单（每次动手前过一遍）

- [ ] 目标程序**已完全退出**（查进程，不是关窗口）
- [ ] 已确认**配置文件的确切路径**（版本/便携/多用户差异）
- [ ] 已**备份**（时间戳命名，保留原始编码的文件副本）
- [ ] 只改**用户点名的那几项**
- [ ] 文件**编码与格式原样保留**（GBK 别按 UTF-8 重写；JSON 别丢掉注释）
- [ ] 改完**逐字节校验**：还原本次改动后应与备份完全一致
- [ ] 明确告知用户**怎么回滚**
